# 成長日記

記錄小孩成長的網頁 App：時間軸、里程碑、WHO 生長曲線、排便／喝奶記錄、搜尋、一鍵打包備份。
只給爸爸媽媽兩人用（設定時各自設一組密碼），名字、主題色、圖示都在網頁上設定，不用改任何程式碼，
一份程式可以讓很多家庭各自部署、各自用自己的資料。

## 功能

- **時間軸**：日常紀錄＋照片影片（手機拍的照片會自動壓縮，原始畫質建議留在 iCloud）
- **里程碑**：第一次笑、第一次翻身、第一次叫爸爸媽媽……內建常見項目，也能自己新增
- **成長曲線**：身高、體重、頭圍，對照 WHO 0-5 歲標準百分位畫圖；可以自訂項目（例如牙齒數量）
- **排便／喝奶快速記錄**：點兩下就能記一筆，每日自動加總；小孩長大用不到時可以在設定頁關掉（資料不會不見）
- **搜尋**：用文字、標籤、拍攝者、是否收藏篩選
- **一鍵備份**：設定頁下載 zip，裡面有文字資料（JSON）、一個可以直接雙擊打開看的 HTML 相簿、全部照片影片
- **主題色與圖示**：在網頁上選顏色（或上傳自己的圖示），不用改程式碼或重新部署
- **PWA**：手機瀏覽器可以「加到主畫面」，開起來像一般 App

## 部署方式一：Railway（推薦，不用自己的電腦開著）

1. 把這個 repo **Fork** 到你自己的 GitHub 帳號。
2. 到 [Railway](https://railway.app)，新增專案 → 選「Deploy from GitHub repo」→ 選你剛剛 fork 的這個 repo。
3. **很重要：加一個 Volume，掛到 `/data`。** 這一步沒做的話，之後每次重新部署（例如更新程式、或 Railway 自動重啟）資料都會消失。
   - 在服務設定裡找到「Volumes」→ 新增一個 Volume → Mount path 填 `/data`。
4. 到「Variables」設環境變數：
   - `DATA_DIR` = `/data`（一定要設，對應上面掛的 Volume）
   - 建議再設 `SETUP_TOKEN`（自己想一串不容易猜到的字串，例如一串亂碼），這樣設定頁才不會被陌生人搶先設定走。
5. 部署完成後，Railway 會給一個網址（長得像 `xxx.up.railway.app`），可以在「Settings → Networking」換成你自己的網域。
6. 用瀏覽器打開 `你的網址/setup?token=你剛剛設的SETUP_TOKEN` 完成初次設定（填小孩名字、生日、主題色、爸媽各自的密碼）。
7. 手機用 Safari 打開網址 → 分享 → 「加入主畫面」，就能像 App 一樣點開用。

## 部署方式二：自己的電腦跑

需要先裝 [Node.js](https://nodejs.org) 22 以上版本。

```bash
npm install
npm start
```

打開瀏覽器到 `http://localhost:3000`，第一次會自動導到初次設定頁。資料存在這個資料夾底下的 `data/`，
只要這台電腦不關機（或換成隨開隨用的小主機），手機連同一個 Wi-Fi 也能打開。如果想長期給家裡以外的人用，
還是建議用上面的 Railway 方式，比較穩定。

## 環境變數

| 變數 | 說明 | 預設 |
|---|---|---|
| `DATA_DIR` | 資料庫與照片影片存放的資料夾。**部署到 Railway 等平台時一定要設成 Volume 掛載的路徑**，否則重新部署資料會不見 | `./data` |
| `SESSION_SECRET` | 登入 cookie 加密用的金鑰，不設會自動產生一組存在 `DATA_DIR` 裡（換主機、換網域時不用特別設） | 自動產生 |
| `SETUP_TOKEN` | 設定過一次之後 `/setup` 就不能再用；但部署剛上線、還沒設定完成前，設這個可以防止別人搶先用你的網址設定走。設了之後要連 `?token=你設的值` 才能打開設定頁 | 不設就不擋 |
| `CHILD_NAME` | 初次設定頁「名字」欄位的預設值（可以不設，進去再自己填） | 空白 |
| `THEME_COLOR` | 初次設定頁「主題色」欄位的預設值（hex 色碼，例如 `#658dc6`），之後也能在設定頁隨時改 | `#658dc6` |
| `PORT` | 伺服器監聽的port，Railway 等平台通常會自動設好，不用自己管 | `3000` |
| `REDIRECT_TO` | 舊站搬家轉址用：設了之後整站會 308 轉到這個網址（同路徑），資料不再寫入舊站。一般使用者用不到這個 | 不設 |
| `SESSION_COOKIE_NAME` | 登入 cookie 的名稱，一般不用設。舊站換程式時沿用舊名稱，大家就不會被登出 | `gd_session` |

## 備份

設定頁有「下載完整備份（zip）」，裡面是全部文字紀錄（`data.json`）、一個可以直接雙擊在瀏覽器打開看的
相簿頁（`index.html`）、以及全部壓縮版照片影片。建議每季下載一次存到家裡的硬碟。

## 更新

之後這個專案如果有新功能或修 bug，想要跟上最新版的話：到你 GitHub 上 fork 的那個頁面按
**「Sync fork」**，Railway 會自動偵測到更新並重新部署（前提是你照上面步驟 3 加了 Volume，不然資料會消失）。
